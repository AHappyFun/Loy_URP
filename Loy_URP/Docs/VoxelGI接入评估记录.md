# VoxelGI 接入评估记录

## 结论

- 评估日期：2026-08-31
- 测试项目：Loy_URP / SmallOutdoor
- Unity：6000.3.15f1
- URP：17.3
- 测试实现：[qstx/com.qstx.voxelgi](https://github.com/qstx/com.qstx.voxelgi/tree/master)
- 最终决定：不采用。已移除 VoxelGI，场景恢复 APV；SSGI 继续保持关闭。

当前场景中，VoxelGI 的低频体素结果在建筑墙面和小房子上形成明显色块、模糊和不连续的间接光，整体稳定性与观感均不如现有 APV。质量问题是本次否决的主要原因。

## 接入范围

本次使用可直接修改源码的本地嵌入式 UPM 包接入，测试内容包括：

- 在 `Deferred_OutSide` Renderer Data 中添加 VoxelGI Renderer Feature。
- 暂时关闭 APV 和已有的 SSGI / SSGI Combine。
- 为 SmallOutdoor 建立约 `64 m × 16 m × 64 m` 的体素范围。
- 使用 `128³` 体素分辨率，单格尺寸约 `0.5 m`。
- 接入自定义 PBR Lit、Terrain 和 GPU 草地。
- PBR Lit 补充发光强度参数写入；Terrain 补充高度图、控制图与地表层采样；草地按间接实例数据参与测试。
- 水面和体积云按要求不接入 VoxelGI。

## 测试中发现的问题

### 1. 建筑表面出现明显色块

中间小房子的墙面最容易暴露问题：间接光呈块状分区，亮度和颜色过渡不连续，并伴随低频模糊。最终合成画面中仍能看到这些问题，不只是 Debug 视图现象。

在当前覆盖范围下，`128³` 对应约 `0.5 m` 的体素尺寸，无法稳定表达小建筑、墙角、薄结构和植被等高频几何。提高到 `256³` 虽可能改善空间精度，但显存、体素化和锥追踪成本会显著增长，不适合在尚未解决基础稳定性问题时直接采用。

### 2. 草地被体素化为纯绿色块

密集草叶写入低分辨率体素后，大量叶片在同一体素中合并，形成接近实心的绿色体积，导致：

- 草地原有的叶片形态消失；
- 绿色反弹过强，出现明显颜色渗漏；
- 遮挡被高估，局部画面变脏、变糊。

测试中随后关闭了草地的体素注入，仅保留草地接收屏幕空间间接光，但这只能规避最严重的绿色块，不能解决建筑上的整体体素精度问题。

### 3. 体素阴影判定异常

启用 VoxelGI 自带体素阴影时，直接光几乎被全部吃掉。诊断统计如下：

- 有效占用体素：42,946
- `N·L > 0` 的体素：34,584
- 启用体素阴影后有直接辐射的体素：45
- 关闭体素阴影后有直接辐射的体素：34,613
- 关闭后有最终辐射的体素：42,946

这说明当前阴影追踪/自遮挡偏移与本场景尺度不匹配。测试只能通过关闭体素阴影继续进行，但会失去该路径应有的遮挡可信度。

### 4. ScreenTrace Debug 容易误判，但最终效果仍不合格

`VoxelGI.ScreenTrace` 显示的是低频辐照度缓冲，并不包含材质纹理细节，因此其观感天然会比最终画面更糊，不能单独把它当成最终合成结果。早期全黑还暴露了配置持久化和外部纹理生命周期问题：

- Volume Profile 子组件最初没有作为子资产持久化，重载后引用变为 `fileID: 0`，导致 GI 实际未生效；
- RenderGraph 中使用 C# 空合并判断 Unity 对象，没有覆盖 Unity 的“假 null”，造成外部纹理为空。

修正上述问题并确认 GI 真正运行后，最终画面依然存在小房子色块、泄漏和整体模糊，所以结论不是由 Debug 显示模式误导得出。

### 5. 性能数据不足以抵消质量问题

一次 Editor 运行时快照约为 `6.53 ms / 153 FPS`，但它不是严格隔离后的 VoxelGI GPU 成本，不能作为正式性能结论。即使性能可接受，当前视觉质量也已经不满足项目要求。

## 回退结果

- 已从 Renderer Data 移除 VoxelGI Renderer Feature。
- 已删除场景中的 Voxel GI Volume、体素范围对象和 Terrain/Grass 贡献器。
- 已删除本地嵌入式 `com.qstx.voxelgi` 包与配套测试资产。
- 已重新启用 SmallOutdoor 的 Probe Volume，并恢复 URP 的 APV Light Probe System。
- 已保留现有 APV 烘焙数据。
- SSGI 与 SSGI Combine 保持关闭。

## 后续若重新评估

只有在实现提供级联/Clipmap 体素、更可靠的保守体素化与自遮挡、针对密集植被的独立策略、稳定的时域滤波，并完成独立 GPU 成本分析后，才建议重新测试。以当前实现直接替代 APV，不符合本场景的质量要求。
